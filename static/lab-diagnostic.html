Diagnostic des verrous du Lab Workspace

Ce contrôle interroge la base réellement utilisée par cette instance Skill-Tree, pas une copie SQLite locale.

Accès sécurisé

Colle le secret de diagnostic configuré pour l’application. Il est envoyé uniquement dans l’en-tête HTTPS, n’est pas enregistré dans le navigateur et le champ est vidé après l’envoi.

Rapport agrégé

Le rapport inclut les écarts de schéma et les prérequis manquants. Il exclut les identifiants d’utilisateurs, les réponses, les preuves et le détail des tentatives.


  


  

    Confidentialité et sécurité
    
    
      
  • La route doit être activée par un secret fort de 32 caractères minimum dans la configuration serveur.
    • 
      
  • La base est ouverte en lecture seule ; ce diagnostic ne réinitialise ni ne synchronise rien.
    • 
      
  • Ne partage pas le secret. Partage uniquement le rapport JSON si un diagnostic complémentaire est nécessaire.
